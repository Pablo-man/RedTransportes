# Gestion de una red de transoportes (personas - articulos)

## Funcionalidades
Administrar nuevos elementos ya sean veiculos, rutas, clientes, asi como la declaracion de roles y grupos de seguridad

Seguimiento en tiempo real sobre el estado del envio

Optimizacion y trazado de rutas mas favorables con posibles paradas 

Metricas de satisfaccion para el aseguramiento de la calidad

* Repartidor
* Receptor
* Analista - CEO
* Administrador
